# CSA_AI-ML_Task2

A simple Linear Regression project that predicts exoplanet equilibrium temperatures using data from the NASA Exoplanet Archive. Linear Regression is performed on 4 versions of the same dataset using gradient descent.

### Files

* `PSCompPars.csv` – Dataset
* `notebook.ipynb` – Jupyter Notebook

### Libraries used

* Python
* Pandas
* NumPy

### How to Run
Keep the CSV and notebook in the same folder and run all notebook cells.
