# CSA_AI-ML_Task2

A simple Linear Regression project that predicts exoplanet equilibrium temperatures using data from the NASA Exoplanet Archive - according to the requirements given for the CSA AI/ML Task. I have performed linear regression on 4 versions of the same dataset using gradient descent.
The Jupyter Notebook already displays all the results and observations.

### Files

* `PSCompPars.csv` – Dataset
* `notebook.ipynb` – Jupyter Notebook

### Libraries used

* Python
* Pandas
* NumPy

### How to Run it yourself
Keep the CSV and notebook in the same folder and run all notebook cells.

### Further Notes
The REPORT topics are covered in the markdowns and comments in the Jupyter Notebook.
